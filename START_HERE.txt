PROBLEM:
  We have 8 security gates. Production has 12. We're missing:
    - Kill Switch (global circuit breaker)
    - Goal Drift (behavioral anomaly detection)
    - Cumulative Limits (lifetime spend cap)
    - Time-Window Limits (rolling daily/weekly/monthly)

SOLUTION:
  Port these 4 features. All are port-ready from production code.

TIME INVESTMENT:
  - Phase 1 (Quick Wins): 5–6 hours → "Wow, that's sophisticated"
  - Phase 2 (Impressive): 10–14 more hours → "Beats most Series A"

TOP 3 TO START WITH:
  1. Kill Switch (2–3h) — flip one switch, halt all payments globally
  2. Trust Tiers (1–2h) — agents graduate from $10/tx to $50k/tx
  3. AnomalyDashboard UI (1–2h) — real-time behavioral monitoring

DECISION:
  □ Do Phase 1 only (5–6h) — enough to impress investors
  □ Do Phase 1 + Phase 2 (20–25h) — production-grade demo
  □ Just Kill Switch + Trust Tiers (3–4h) — MVP narrative upgrade
